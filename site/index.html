Zane benchmarks

The pinned runs of the two benchmarks in the specification repository.

  • langbench — Zane against C, C++, Rust, Go, D and Zig

    The same programs written in each language, built by each language's compiler, with Zane's built by a released zanec. Timed as whole processes, with build times beside run times.

  • memorybench — the memory model, in C

    A C harness that models the memory design: arenas, settled and roaming owners, references and lists, measured against plain C allocation patterns.
Sources: zane-lang/spec, in langbench/ and memorybench/.
